## 实现方案：页面关系图（Storyboard 视图）

**选型**：`@xyflow/react`（React Flow 12，MIT）做画布，`@dagrejs/dagre` 做自动布局。React 19 兼容、TS 原生、自定义节点就是普通 React 组件，可直接复用现有卡片样式。用户已确认：连线自动推导、第一版只读概览、在 /dashboard 做视图切换。

### 1. 后端（不改表结构）

- `apps/server/src/routes/pages.ts` 新增 `GET /api/pages/graph`：
  - 复用 `listPages`（pages.ts:81-104）的 RBAC 可见性过滤，取可见页面的 `schema`（草稿字段，编辑者视角）。
  - 连线推导：递归扫描每个节点 `props`，凡 key 为 `href` 或以 `Href` 结尾的字符串值都收集（自动覆盖 navbar/footer 菜单、hero/cta/imageText 按钮、carousel slides、pricing plans，未来新物料无需改代码），并记录来源物料类型。
  - 归一化与匹配：`/` → `/home`；忽略外链、`mailto:`/`tel:`/`#` 锚点、`RESERVED_SLUGS`（dashboard/api 等）；命中其他页面 slug → 生成边，同一对页面多条 href 去重为一条（via 元数据保留来源物料列表）；像 `/xxx` 但无对应页 → 挂到虚线占位节点「/xxx 未创建」（顺带实现死链可视化）；自环跳过。
- `packages/schema/src/index.ts` 新增 `PageGraphResponse` DTO（pages / edges / placeholders）。

### 2. 前端

- `apps/web/src/lib/api.ts` 加 `getPageGraph()`。
- `apps/web/app/dashboard/page.tsx`：统计条旁加「卡片 / 地图」分段切换，卡片视图原样保留。
- 新组件 `apps/web/src/components/dashboard/page-graph.tsx`：
  - ReactFlow 全高画布，dagre 左→右分层自动布局，`fitView`，带 MiniMap、缩放控制、网格背景。
  - 自定义 `pageNode` 节点：紧凑版现有卡片（名称、`/{slug}` 外链图标、发布/草稿 Badge、协作 Badge），点击节点进 `/dashboard/editor/{id}`。
  - 占位节点：灰色虚线边框 + 「未创建」标识，出边为虚线。
  - 地图视图只读，无新建/删除等操作，动作回卡片视图做。

### 3. 依赖与验证

- `apps/web` 新增 `@xyflow/react`、`@dagrejs/dagre`。
- 起 docker 栈验证（注意实际端口 5432/6379）：建两个互相链接的测试页验证连线、改一个 href 指向不存在页面验证虚线死链展示；**只动自建测试数据，不碰演示页**。
- pnpm typecheck / build 通过。
