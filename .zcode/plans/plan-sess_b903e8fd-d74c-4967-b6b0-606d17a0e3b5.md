# 前端 UI 精装修方案（现代 SaaS 风 + 亮暗双主题）

**风格基调**：indigo→violet 品牌色 + 克制渐变点缀 + 多层阴影精致卡片，对标 Linear / Vercel / Webflow。全部通过语义 token 实现，为暗色模式打基础。

**关键约束**：物料组件（发布页内容）是独立真实网站，继续用显式色值，**不接入平台暗色主题**（平台切暗色时发布页内容不受影响）；编辑器 UI 全部收敛到语义 token（消灭硬编码 slate/indigo-*），暗色才能全局生效。

---

## 第 1 步：设计系统基建（token + 主题机制）

- `apps/web/app/globals.css`：
  - `:root` 品牌化重调：`--primary` → indigo-600、`--ring` → indigo、`--radius` 调至 0.625rem，补充 `--color-*` 渐变辅助变量
  - 新增 `.dark` 全套暗色 token（zinc-950 底、提亮卡片与边框、indigo-500 主色）
  - Tailwind v4 类名式暗色开关：`@custom-variant dark (&:where(.dark, .dark *))`
  - 附带：暗色滚动条、`::selection` 品牌色、画布点阵网格背景 utility
- 新建 `apps/web/src/components/theme/`：
  - `theme-provider.tsx` — React Context + localStorage + 系统偏好监听（light/dark/system）
  - `theme-toggle.tsx` — 太阳/月亮切换按钮
  - `layout.tsx` 注入无闪烁内联脚本（首屏前设置 `.dark` class），`<Toaster>` 跟随主题
- 字体：不引入外部字体（构建需联网、风险高），仅优化系统中文字体栈

## 第 2 步：`@lc/ui` 补件

- 新增 `card.tsx`（Dashboard/兜底页用）、`skeleton.tsx`（替代手写 animate-pulse），更新包导出
- 现有 11 个组件全走 token，自动适配暗色，基本不动

## 第 3 步：Dashboard 精装（`apps/web/app/page.tsx`）

- 头部：渐变 Logo 方块（indigo→violet + Globe 图标）+ 大标题 + 右侧主题切换
- 新增统计条：页面总数 / 已发布 / 草稿 三个 stat 卡（渐变图标 chip），不加新 API，纯前端从列表推导
- 页面卡片升级：顶部装饰性"页面封面"（按页面名生成的渐变色块 mock 预览）、hover 抬升 + 品牌色描边、状态 Badge 加圆点指示
- 空状态、三个 Dialog 细节打磨

## 第 4 步：编辑器精装

- `topbar.tsx`：渐变 Logo、主题切换、设备切换改为 iOS 式分段控件（bg-muted 容器 + 活动项浮起）、发布按钮渐变
- `material-panel.tsx`：物料卡片图标改分类色系 chip、hover 精致化；大纲树 token 化
- `canvas.tsx`：画布底改点阵网格纹理（暗色自适应）、白色纸面加双层阴影、悬浮工具条/空态拖放区全部 token 化
- `property-panel.tsx`：新建共享 `color-field.tsx` 美化原生取色器（自定义色板 swatch 覆盖 + hex 输入 + 棋盘格背景）；数组编辑器、区块样式卡片化、全部 token 化
- `editor-client.tsx`：品牌化加载屏（渐变 spinner）与错误态卡片

## 第 5 步：兜底页（新建）

- `app/not-found.tsx`：品牌 404（渐变大字 + 返回首页）
- `app/error.tsx`：品牌错误页 + 重试按钮
- `app/loading.tsx`：路由级骨架屏

## 第 6 步：物料升级（`packages/materials/src/blocks/` 9 个组件）

发布出来的网站更好看，保持显式色值、兼容导出 HTML：
- **Hero**：默认深色底加径向光晕装饰、主按钮渐变+悬浮位移、标题渐变文字选项式点缀

- **Cta**：渐变面板 + 光晕
